התקנת המסד FoodRush

צריך את הדף הזה רק אם המסד לא קיים במחשב. המחשבים בכיתה מתאפסים בכל לילה, ולכן בתחילת שיעור בדרך כלל מתקינים מחדש. זה לוקח פחות מדקה.

איך יודעים אם המסד קיים? ב־SSMS, ברשימת המסדים בסרגל הכלים. אם FoodRush לא מופיע שם, מתקינים.

  1. הורדת הקובץ foodrush_db.sql
  2. ב־SSMS: File → Open → File, ובוחרים את הקובץ מתיקיית ההורדות (Downloads).
  3. לוחצים F5 ומחכים שבשורת המצב בתחתית החלון תופיע ההודעה Query executed successfully.
  4. פותחים חלון חדש עם New Query, בוחרים FoodRush ברשימת המסדים, ובודקים שהכול עובד: 
    SELECT COUNT(*) FROM orders
    התשובה צריכה להיות 1250. אם מופיעה השגיאה Invalid object name 'orders', בוחרים FoodRush ברשימת המסדים בסרגל הכלים.

חשוב: את התרגילים כותבים בחלון החדש. לחיצה על F5 בחלון של הקובץ תטען את כל המסד מחדש.
